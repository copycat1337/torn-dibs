About this project

CAT Dibs is a Torn City userscript paired with a small Node.js service. It adds claim buttons to the faction members list so faction members can coordinate who is attacking whom during ranked wars.

Requires a running node js server, a Torn API key with faction access, and a userscript manager such as Tampermonkey or ScriptCat. The server must be reachable by every member using the script.

Installation

  1. Install a userscript manager, such as Tampermonkey or ScriptCat.
  2. Install the CAT Dibs userscript (dibs.js) from this repository or your published raw script link.
  3. Confirm the installation in your userscript manager.
  4. Open your faction page on Torn and use the userscript menu to select Set Torn API Key. Complete registration, then reload the page.

Requirements & notes

  • A browser supported by your userscript manager (Tampermonkey or ScriptCat).
  • CAT Lite Node.js server running and reachable on port 3701.
  • Your Torn API key and faction ID configured for the server.
  • Claims synchronize through the CAT Lite server; the server must stay online.

How to use

Use the CALL button beside a faction member to claim that player as your target. The button then shows the name of the member who has claimed the target.

  • One claim per target: once a player is claimed, another faction member cannot claim that same target.
  • Claim ownership: you can manually cancel your own claim; other members can see who owns it.
  • Hospital tracking: the script marks targets that are in the hospital and checks whether a claim can be released.
  • Combat-only auto-release: a claim is released after the script has observed the target outside hospital and later detects a recognized combat hospitalization. Existing hospital stays, self-hospitalization, overdoses, accidents, and unknown reasons do not automatically clear a claim.
  • Ipecac: taking Ipecac does not reset or release the claimed target.
  • Ranked-war detection: CAT Lite checks your faction's current ranked-war opponent and monitors both faction rosters.

Default polling: claims sync every 3 seconds, the page buttons refresh every 2 seconds, target status is checked every 20 seconds, and the ranked-war opponent is checked every 120 seconds.

Server setup

In the server project directory, install dependencies, configure the environment, initialize the database, and start the service:

npm install
# Configure .env:
# FACTION_ID=YOUR_FACTION_ID
# API_TOKEN=YOUR_TORN_API_TOKEN

npm run db:init
node server.js

# Or use Docker Compose:
docker compose up -d

Set FACTION_ID and API_TOKEN in the server's .env file. The default server port is 3701. In dibs.js, update both the SERVER constant and the @namespace metadata to your server's public IP or domain.

To reset the database (this wipes existing claim data), run npm run db:reset.
